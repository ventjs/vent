# Changelog

All notable changes to VentJS will be documented in this file.

This project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html) and the [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format.

## [1.0.0] - Unreleased

### Added

- Initial official VentJS release.
- Modular backend architecture powered by Bun and TypeScript.
- HTTP routing with support for standard HTTP methods.
- Middleware pipeline for handling request workflows.
- Module system for organizing application features.
- Built-in validation system.
- CLI scaffolding with independent REST API and GraphQL templates.
- Module generator through the VentJS CLI.
- TypeScript-first developer experience.

### Documentation

- Added project documentation and setup instructions.
- Added contribution guidelines.
- Added security policy.
- Added code of conduct.
- Added Claude Code and AI coding assistant instructions.

### Changed

- Established VentJS as the official framework identity.
- Updated project branding, package references, and CLI naming to VentJS.
